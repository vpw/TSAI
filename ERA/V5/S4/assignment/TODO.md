## Headline findings from the run

- English-tuned Gopher/C4 rules keep **11,820** documents; script-aware rules keep **60,943** —
  **49,163 documents / 35.6M tokens** of good Indic text an English-tuned filter destroys.
  Per language: Hindi 2.6% → 97.8%, Telugu 4.9% → 86.5%, Assamese 1.5% → 94.8%, English 96.6%
  either way. Two rules do nearly all of it: `common_stopwords_present` (English function words)
  and `lines_end_in_terminal_punct` (knows `. ! ?`, not the danda `।`).
- Language ID caught **161** mislabelled documents; trusting the folder path catches 0. The
  Assamese folder really does contain Bengali: detection moves 52,676 tokens out of `asm` and
  finds 41,973 tokens of `ben` that no folder claims.
- The `te`/`tel` ISO bug would have wrongly rejected **64,308 of 64,712** documents.
- Dedup: **265 exact**, **13 near** duplicates — Sangraha's duplication is verbatim, not
  paraphrased. 2 were catchable only by the global pass.
- Decontamination against MMLU / GSM8K / HellaSwag / MILU (hi, te, bn): **457 documents dropped**
  (0.75%), 813k distinct 13-gram fingerprints.
- Measured fertility runs to **4.25 tokens/word** for Assamese; `words × 1.3` is off by −23.8%
  across the slice.
- Honest negatives kept in: Sangraha is clean at the character level (117 noise characters in
  64,712 documents), 0 ghost tags found, the classifier gate dropped only 34 documents, and PII
  masking made the corpus **longer** in tokens, not shorter — the opposite of the session's
  worked example, for a reason the widget explains.
