# Task
This directory is a part of the assignments for the ERA V5 course of The school of AI (TSAI).
Specifically this is for the fourth session (S4).

The S4-assignment.md file lists the exercises to be done in this session. Please refer that
for the details of any section.

The final widget file (maybe alongwith any JS) will have to be uploaded to a Netlify site.

# Details
The session covers a data cleaning and deduplication pipeline (8 stages: extract, normalize,
language ID, quality filter, deduplicate, PII scrub, decontaminate, manifest). The session
writeup is in resources/s4-session.md and the live-class transcript is in
resources/s4-transcript.md. Real numbers from every interactive widget on the session page
(exact stage yields, defect callouts, MinHash/LSH worked example, PII/language-ID cases,
manifest gating logic) have already been extracted into resources/s4-widget-data.md — use
that instead of re-scraping the page.

The assignment wants: a count and description of the strategies covered, a picked 10-100M
dataset (look first at datasets encountered in the S3 assignment, ../../S3/assignment/), the
cleanup actually applied to it (what/why/how), any other strategy or concern handled, and
final statistics — all presented as a widget, deployed to Netlify.

As a capable agent, plan to (1) enumerate and describe the strategies from the session
material, (2) pick and obtain a suitable dataset, (3) actually apply the cleaning stages to
it and record real before/after statistics, (4) build the widget, (5) deploy and share the
link. TODO.md tracks progress on these steps.
