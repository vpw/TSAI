This directory is a part of the assignments for the ERA V5 course of The school of AI (TSAI).
Specifically this is for the second session (S2).

The S2-assignment.md file lists the exercises to be done in this session. Please refer that for the details of any section.

Each exercise (or part/section) needs an HTML + JS script to be implemented to demonstrate the concept in that part. The final submission should consist of a single HTML + JS deliverable which will have all the sections - perhaps as a set of tabs on the top.

You can use any good JS framework e.g. React.js etc. which is suitable for the scope of the assignment.

The final single file (maybe alongwith any JS) will have to be uploaded to netlify site.
