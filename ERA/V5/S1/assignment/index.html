📌 S1-1: Activations Exist For A Reason

Claim: A model with no nonlinearity can only draw a straight boundary, so it cannot separate two interleaved/concentric rings; adding one ReLU hidden layer can wrap around the ring.
💡 The Key Insight: Linear models (no activation) can only learn linear decision boundaries (straight lines). With ReLU activation, the network can create non-linear boundaries that can separate complex patterns like concentric rings.

📌 S1-2: Depth Without Nonlinearity Is A Lie

Claim: Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer. Inserting ReLUs between the same five layers suddenly solves it.
💡 The Key Insight: Mathematically: W₅·W₄·W₃·W₂·W₁ = W_final (just another matrix!). Without nonlinearity, deeper networks are just one linear transformation - no extra power! ReLU breaks this chain.

📌 S1-3: Embeddings Learn Similarity From Next-Token

Claim: Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens, though similarity was never supplied.
💡 The Key Insight: The grammar never predicts "my own category" directly - animals are followed by verbs, verbs are followed by animals or fruits, and fruits are followed by animals. Same-category tokens still end up with similar embeddings, because they share the same next-token distribution (e.g. every animal is always followed by a verb) - even though we never told the model what a "category" is!

📌 S1-4: Memorization vs Generalization

Claim: A high-capacity model on tiny data drives train loss to ~0 while held-out loss stays high; growing the dataset closes the gap.
💡 The Key Insight: With just 20 training samples, a large neural network can memorize the entire dataset (train loss → 0), but performs terribly on unseen data. As we increase training data to 200 and 2000, the model must actually learn patterns, and train/test gap shrinks dramatically!
